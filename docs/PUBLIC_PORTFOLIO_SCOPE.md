# Phạm vi repository public

## Có trong repository

- Tài liệu mô tả sản phẩm và case study.
- Sơ đồ kiến trúc ở mức khái quát.
- Hình ảnh đã loại bỏ thông tin nhận dạng.
- Snapshot giả lập.
- Module Python minh họa validation/freshness.
- Unit test cho module minh họa.

## Không có trong repository

- Mã nguồn EA `.mq5/.mqh` và file biên dịch `.ex5`.
- Source Dashboard/Runtime thương mại hoặc EXE phát hành.
- Logic tín hiệu, entry, DCA, hedge hoặc điều kiện thoát.
- Private signing key, HMAC secret, license và activation code.
- Token Remote, mã ghép nối, IP VPS và cấu hình thật.
- Snapshot, log hoặc thông tin tài khoản khách hàng.

Việc loại bỏ các thành phần trên là chủ ý bảo vệ sở hữu trí tuệ và dữ liệu, không
phải dấu hiệu repository bị thiếu file.
